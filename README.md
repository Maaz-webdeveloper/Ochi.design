# 🎭 Ochi Design Agency — Clone

A pixel-perfect, interactive, and fully responsive clone of the award-winning **Ochi** design agency website. Built using **React.js**, **Tailwind CSS**, **Framer Motion**, and **Locomotive Scroll**.

---

## 🚀 Live Demo

🔗 **Live Website:** [https://ochidesign-two.vercel.app/](https://ochidesign-two.vercel.app/)

---

## ✨ Features

- 📱 **Fully Responsive Layout:** Customized responsive design tailored for both desktop and mobile viewports.
- 📜 **Smooth Scrolling:** Integrated with `Locomotive Scroll` for an effortless parallax scrolling experience.
- 👀 **Interactive Mouse Tracking:** Custom-engineered eyes component that tracks cursor position dynamically in real time.
- ⚡ **Framer Motion Animations:** Smooth hover transitions, letter-by-letter text reveals, and interactive card animations.
- 🎨 **Minimalist UI:** Modern typography and layout styled strictly with **Tailwind CSS**.

---

## 🛠️ Tech Stack

- **Framework:** [React.js](https://react.dev/) (Vite)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Scroll Engine:** [Locomotive Scroll](https://github.com/locomotivemtl/locomotive-scroll)
- **Icons:** [React Icons](https://react-icons.github.io/react-icons/)
